# Morphing de imágenes con transporte óptimo dinámico

Proyecto de MA4703-1 Control Óptimo (Universidad de Chile, 2026).

🌐 **Página del proyecto:** https://USUARIO.github.io/NOMBRE-REPO/

![](assets/morphing_principal.gif)

## Estructura

```
_quarto.yml      configuración del sitio
index.qmd        página principal (texto, fórmulas, GIFs)
proyecto.ipynb   notebook con el código (se muestra en la pestaña "Código")
assets/          imágenes y GIFs
docs/            sitio generado (no editar a mano)
```

## Actualizar la página

```bash
quarto preview      # ver cambios en vivo en el navegador
quarto render       # genera docs/
git add . && git commit -m "Actualiza página" && git push
```
